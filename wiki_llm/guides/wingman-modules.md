# Wingman modules

Reviewed 2026-11-20.

## Which model answers a question?

Wingman's main conversation model answers the player and can call skills. Support handles background tasks such as conversation summaries. WikiLLM supplies evidence to whichever Wingman calls it. [Wingman AI](https://github.com/ShipBit/wingman-ai)

## Alarms and game warnings

Enhanced Timers can set an alarm or reminder. Wailing Wilma reads supported status displays to report game warnings. A wiki entry can explain what an indicator means. A warning about the player's ship needs a current observation. [Enhanced Timers](https://github.com/Fowlplaychiken/wingman-enhanced-timers) · [Wailing Wilma](https://github.com/Fowlplaychiken/Wailing-Wilma)
